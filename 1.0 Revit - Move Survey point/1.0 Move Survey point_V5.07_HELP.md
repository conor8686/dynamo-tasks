# Move Survey Point V5.07 - Help Sheet

Reference for `1.0 Move Survey point_V5.07.dyn`. Engine: CPython3 throughout.

## What it does

One graph, four separate location/setup tasks, organized as titled groups:

1. **Project Base Point** - sets the Project Base Point's N/S, E/W,
   Elevation and Angle to True North via `ActiveProjectLocation`, and also
   writes the same values onto the Survey Point's parameters directly.
2. **Survey Point - Internal** - finds the (shared) Survey Point, forces its
   physical position back to the Internal Origin `(0,0,0)`, then sets its
   N/S, E/W, Elevation and Angle-to-True-North *parameters* to the target
   values (standard Revit practice: the point symbol stays at the internal
   origin, the parameters carry the real-world coordinate).
3. **"Optional, but do."** (the author's own group title) - sets the
   project's length units to Meters (3 decimals, symbol "m"), then creates
   (or reuses) a Level Type called `MWP_Circle Head - Survey point` with
   "Elevation Base" set to Survey Point, and reassigns **every Level in the
   project** to that type.
4. **Acquire Coordinates** (untitled group, bottom-left) - temporarily
   links the `.rvt` file you point it at, calls `AcquireCoordinates` to pull
   that file's shared coordinate system into the current project, then
   deletes the temporary link - leaving the acquired coordinate system
   behind without a permanent link.

## Inputs to set before running

| Input | What it is | Example |
|---|---|---|
| `XYZ_E/W,N/S,Elev_Project Base Point` | Comma-separated target coordinates for the Project Base Point, in meters | `83487.960,332147.281,311.303` |
| `Angle°` | Angle to True North, in degrees | `347.21` |
| `Revit` | File picker - the `.rvt` to pull shared coordinates from (step 4) | a linked survey/site model |

**Watch out:** the default value on the coordinate string has a stray
line-break baked in (`83487.960,332147.281` + newline + `,311.303`). Retype
it as one clean comma-separated line before running, so `String.Split(",")`
doesn't hand a value with an embedded `\r\n` to `String.ToNumber`.

## Order of operations / notes

- Steps 1 and 2 both run automatically together - there's no toggle to do
  only one. If you only want to move the Survey Point and leave the Project
  Base Point untouched (or vice versa), you'd need to disable the other
  group's node manually in Dynamo first.
- Step 3 has its own Boolean input and is explicitly labeled "optional, but
  do" by whoever built this - meaning skip it only if you have a reason to,
  not by default. It changes units for the **whole project** and
  reassigns **every Level**, so double-check the target Level Type name if
  this project already uses a different naming convention.
- Step 4 (Acquire Coordinates) is independent of 1-3 and only needs the
  `Revit` file input. It creates and deletes a temporary link as part of
  its own transaction - if it fails partway through, check the model for a
  leftover link that didn't get cleaned up.
- A "Review" group (parsing a second, separate coordinate string,
  `83675.9501,331793.1684,0`) exists purely to display/verify a value - it
  isn't wired into the Survey Point-setting logic, so editing it has no
  effect on what actually gets written to the model.
